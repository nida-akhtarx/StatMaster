
# 📊 StatMaster – Interactive Data & Probability Suite

StatMaster is a Python and Streamlit based web application designed for Statistics students.

## 🚀 Features

- Descriptive Statistics
- Mean, Median and Mode
- Standard Deviation
- Outlier Detection
- Frequency Distribution
- Normal Distribution
- Binomial Distribution
- Random Sampling Simulation
- Hypothesis Testing (Z-Test, T-Test and Chi-Square)

## 🛠️ Technologies Used

- Python
- Streamlit
- Statistics
- Mathematics

## 📚 Python Concepts

- Object-Oriented Programming
- Encapsulation
- Inheritance
- Abstraction
- Loops
- Functions
- Match Cases
- Lists, Dictionaries and Tuples

## ▶️ How to Run

Install Streamlit:

```bash
pip install streamlit
```

Run the application:

```bash
python -m streamlit run main.py
```
